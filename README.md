# Hekima Health Clinic Website 🏥
**Live URL:** [https://hekimahealth.co.ke](https://hekimahealth.co.ke)  
**Location:** Kajiado County, Kenya

## 📋 Project Overview
Hekima Health Clinic is a professional, responsive web platform designed to bridge the gap between healthcare providers and residents in Kajiado County. The project focuses on accessibility, modern UI/UX principles, and practical medical utility.

## 🚀 Features
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
* **Appointment Booking:** Functional contact form with regex-based phone validation for Kenyan numbers.
* **Service Showcasing:** Highlighting Maternity, Lab, and General Consultation services.
* **Social Integration:** Direct links to platform registration pages for community engagement.
* **Local Context:** Tailored specifically for the Kajiado regional environment.

## 🛠️ Tech Stack
* **Language:** HTML5, CSS3
* **Icons:** FontAwesome 6.0
* **Typography:** Google Fonts (Segoe UI/System Sans)
* **Deployment:** GitHub Pages (Recommended)

## 📁 File Structure
* `index.html` - Contains the structure, styling, and basic interactivity logic.
* `README.md` - Project documentation and presentation guide.
